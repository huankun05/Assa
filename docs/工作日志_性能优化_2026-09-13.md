## 1. 问题与根因

用户反馈：启动时或运行中明显卡顿，鼠标走不动；怀疑是轮询。

调查结论（主进程 + 渲染层）：

| 现象 | 主因 |
|------|------|
| 启动时鼠标走不动 | `whenReady` 一把梭初始化 + Splash WebGL 波浪与视频并发 + 字体 base64 主线程解码 + 50ms 鼠标 IPC 轮询 |
| 展开 Overview / 点静音瞬间冻结 | `media.ts` 仍用 spawnSync 调 .NET helper（实测阻塞主进程 80–380ms） |
| 播放音乐时持续卡 | 进度 ~15Hz 写 store + 根组件无 selector 全量订阅 → 整树 re-render |
| 间歇性数秒冻结 | tasklist 失败时 `execSync` PowerShell 回退，被 4s 轮询踩中 |
| 长截图期间鼠标发滞 | 主进程 30ms 光标轮询 + 同步 GDI + 全帧像素遍历（**本批未改**） |

## 4. 设计要点（避免回退）

1. **主进程禁止 `spawnSync`/`execSync` 做系统探测**（音量/亮度已有 daemon 注释警告；本次 media.ts 与 PowerShell 回退已统一为异步）。
2. **高频状态不要写进根 store 的无 selector 订阅者**；`currentPositionMs` 由歌词组件自行 selector 订阅，桥接逻辑用 `getState()` 读当前值。
3. **启动关键路径只保留窗口/托盘/IPC/热键**；侧车、扫描、轮询类服务统一 `setTimeout` 错峰。
4. **长截图会话内 30ms 轮询 + 同步 GDI 仍在**，仅在长截图激活期运行；后续单独优化。

## 附录 C · 托盘退出修复（同日）

### 根因
1. 设置窗口 `close` 一律 `preventDefault` → 改为隐藏保活；`app.quit()` 会等窗口关闭，被卡住  
2. 托盘/快捷键/IPC 都是裸 `app.quit()`，清理路径分散  
3. will-quit 含杀子进程，Windows 上可能挂住  

### 修复
- 新增 `quitAppFast()`（`appRestart.ts`）：统一清理 → `app.exit(0)` → `process.exit(0)` → 外部 taskkill 兜底  
- 托盘「退出」、退出快捷键、`app:quit`、`window-all-closed` 统一走 `quitAppFast`  
- 设置窗口在 `isApplicationQuitting()` 时放行 close  
- 抽出 `runAppExitCleanup()`，与 will-quit / 重启清理共用  

### 验证
- hotkeyService / appLifecycle 测试 6 通过

## 附录 D · 反复弹出「汐月正在重新启动」修复（同日）

### 根因
1. **单实例锁失败后未 return**：只 `app.quit()`，模块初始化仍继续（whenReady/建窗/托盘），soft-restart 窗口期易出现多实例叠托盘  
2. **force-kill VBS 无条件 taskkill**：soft-restart 后新 Electron 若复用 PID，会被 1.3s 后的兜底杀掉 → 再次异常退出/再拉起  
3. **残留 soft-restart.flag**：异常退出时 flag 未删，下次退出再触发 electron-vite 原地重启  

### 修复
- 锁失败：`app.exit(0)` + `process.exit(0)`，**立刻退出不再初始化**  
- force-kill：VBS 内 WMI 确认进程仍在再 kill；干净退出时 `unlink` 掉 VBS；`process.on('exit')` 取消  
- whenReady：清理 >8s 的过期 `soft-restart.flag` 与历史 `assa-force-kill-*.vbs`  

### 验证建议
- 托盘重启只弹一次提示，重启完成后不再反复弹  
- 可先 `npm run clean:dev-processes` 清掉 11:48 残留的僵尸 electron 再测
