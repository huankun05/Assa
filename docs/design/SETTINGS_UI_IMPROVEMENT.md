# 设置 UI 改进方案（审美向）

> 状态：方案 + 浏览器示意稿（2026-09-13）  
> 参考：Linear 设置、Raycast、Arc、Apple 系统设置、Notion、VS Code、Discord 设置等公开产品形态  
> 示意：`settings-ui-preview/index.html`（cwd 下，浏览器直接打开）

---

## 1. 现状问题（对照截图）

| 问题 | 原因 |
|------|------|
| 灰噗噗、无风格 | 大面积 `rgba(text,α)` 灰底 + 点阵，层次靠 opacity 堆，缺少「纸面」基色 |
| 图标不成套、像贴图 | 原 `img` 混用；后改 mono mask 仍放在 **80px 装饰位**，SVG 线宽不一，放大发虚 |
| 手感不对 | desk-pet 的「大装饰卡」依赖 **duotone 大图标**；汐月 mono 小图标撑不起 96px 装饰位 → 空、廉价 |
| 结构偏「展览」不偏「工具」 | 每类一张大卡信息密度太低，不像设置，像落地页 |

**结论：** 不能继续用「desk-pet 大装饰卡 + mono 小图标」硬拼。应改成 **工具型设置**：密度合适、图标小而统一、搜索是一等公民。

---

## 2. 竞品在做什么（可迁移点）

| 产品 | 可取 | 不取 |
|------|------|------|
| **Linear** | 列表密度、命令/搜索优先、中性灰 + 单一品牌色、行高统一 | 过冷过黑，汐月要更亲和 |
| **Raycast** | 设置分组清晰、行式设置项（标题+描述+右侧控件） | 全黑玻璃对浅色窗不友好 |
| **Apple 设置** | 左导航+右详情的信息架构清楚、行式分组、控件克制 | 用户已否决双栏；我们保留单栏钻取 |
| **Arc** | 卡片阴影克制、圆角统一、hover 微妙 | 过度装饰插画 |
| **Notion** | 图标 16–20 + 文案层级、列表可扫读 | |
| **VS Code** | 分组小标题 + 行设置 | 过密、开发向 |

**共同点：**  
1）**行式设置项**（不是大装饰卡堆功能）  
2）**小图标（16–20px）成套**  
3）**一种强调色**，只在选中/hover/开关  
4）**搜索/命令**常驻  
5）**动效短**（120–200ms）

## 3. 设计方向（定稿）

### 3.1 气质

> **冷静的工具面板** + **一点汐月蓝**  
> 像「系统设置」的清爽，而不是「活动页」的海报。

### 3.2 色彩（浅色）

| Token | 值 | 用途 |
|-------|-----|------|
| `--s-bg` | `#f4f6fa` | 窗内容底（冷浅灰，不发黄） |
| `--s-surface` | `#ffffff` | 卡/行容器 |
| `--s-border` | `#e6eaf2` | 1px 描边 |
| `--s-ink` | `#151820` | 主文字 |
| `--s-muted` | `#6b7386` | 说明 |
| `--s-accent` | `#64aaff` 系 | 仅交互（与岛 accent 同族） |
| `--s-accent-soft` | `#e8f2ff` | 选中底 / chip |

深色：`#0e1014` / `#171a21` / 边框 `#2a2f3a`，accent 同族提亮。

### 3.3 字体层级

| 级 | 字号/字重 | 用途 |
|----|-----------|------|
| 页标题 | 22px / 600 | 设置、外观…（**不要 30px 展览标题**） |
| 页副题 | 13px / 400 muted | 一行说明 |
| 分组题 | 12px / 600 muted uppercase 或 小灰条 | 「外观」「隐私」 |
| 行标题 | 14px / 500 | 主题外观 |
| 行说明 | 12px / 400 muted | 深色 / 浅色… |

### 3.4 布局

```
┌──────────────────────────────────────────┐
│  设置                          [搜索…]   │  顶栏 56–64px，搜索宽 280–360
├──────────────────────────────────────────┤
│  快速入口                                │  可选：4 个紧凑 chip
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐            │
│  │外观│ │AI  │ │系统│ │媒体│            │  小图标 18 + 名，非大装饰卡
│  └────┘ └────┘ └────┘ └────┘            │
│                                          │
│  全部分类                                │  组标题
│  ┌──────────────────────────────────┐  │
│  │ [小图标] 外观          ›          │  │  行高 56–64，非 96 装饰卡
│  │          主题、布局、位置与动效      │  │
│  └──────────────────────────────────┘  │
│  …                                      │
└──────────────────────────────────────────┘
```

点入分类 → **行式设置组**（Raycast/Apple）：

```
外观
  主题外观          [深色 ○ 浅色 ● 跟随]
  灵动岛透明度      ——●——
  独立窗控制按钮    [开关]
```

### 3.5 图标

- **列表/行内：18–20px**，同一 stroke 体系（Lucide / 现 mono 仅用小尺寸）
- **禁止** 72–96px 装饰图标（除非有成套插画）
- 颜色：默认 muted，hover/active accent

### 3.6 动效

- 入场 160ms ease-out，位移 6px（不要 250ms+大扫入）
- hover 只换 border/bg 150ms
- 搜索下拉 120ms

### 3.7 禁止

- 点阵纹理当风格
- 灰底 + 低对比文字
- 大装饰图标撑卡
- 多套按钮语言并存
- 页头 30px「海报标题」

## 4. 实施顺序

| 阶段 | 内容 | 工作量 |
|------|------|--------|
| P0 | 色板 + 页头/搜索/分类**行列表**替换大装饰卡 | 中 |
| P0 | 分类图标改 18px 行内 mono | 小 |
| P1 | 详情页分区头 + 行组件（Switch/Segment 统一） | 大 |
| P1 | 深浅色对照 | 中 |
| P2 | 删点阵/旧玻璃装饰 CSS | 小 |

**功能页组件仍复用**，先换壳与列表语言。

---

## 5. Decision Trace

1. **放弃 desk-pet 大装饰卡** — mono 小图标撑不起 96px 装饰位；产品是工具不是海报。  
2. **改为行式 + 紧凑快速入口** — 对齐 Linear/Apple，信息密度与可扫读性。  
3. **强调色只用于交互** — 避免灰底刷蓝变「脏」。  
4. **搜索顶栏常驻** — 一级入口，而非卡片附属。
