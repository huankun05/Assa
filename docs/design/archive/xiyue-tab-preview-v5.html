方案副行文案结论理由
A · 问候语 下午好，有什么可以帮你？ ✔ 推荐 最像「人」：随时间变化（早/午/晚）、有温度、零学习成本。文字长度刚好填满副行，视觉最平衡。断行时 ellipsis 也不违和。
B · 待命状态 待命中 · 随时开始 △ 备选 信息量与主行「汐月·开心」重复（都在说状态），略显啰嗦；且不变，久看无感。
C · 上次对话 上次：翻译「Hello」 △ 备选 信息量最足，但① 需要新增「读取最近一条会话」的数据链路；② 首次使用无内容会空；③ 涉及历史内容，岛上是常驻可见的，隐私上略敏感。
D · 模型信息 GPT-4o ✘ 暂缓 按你说的后续再定，本轮不引入。
E · 快捷 Prompt 试试问：总结剪贴板 ✘ 不做 会变成可点击项 → 与右侧两个按钮职责重叠，且抬高信息密度，违背简约。

为什么头像改成这样
  • 圆形头像框 = 角色/人物（不是动物、不是图标），符合「AI 助手是一个人」的定位
  • 人脸（眼 + 嘴） = 表情载体，四个状态只换眼嘴，成本极低
  • 右上 ✦ sparkle = AI 身份标识（恒定不变），一眼区分「真人头像」与「AI 头像」
  • 全部为单色 currentColor，可被 filter: brightness(0) invert() 主题适配；后期换正式美术资源时，只需替换 <img src>，结构不动
尺寸自检
  • 头像 34px + gap 9 + 两行文字（12px + 2 + 10px ≈ 29px）→ 行高 34px
  • 60px 岛：上下各留 13px；72px 岛：上下各留 19px —— 宽松不溢出
  • 副行超长走 text-overflow: ellipsis，窄岛也不会撑破
