## 0. 一页总览

| 区 | 已上线（不动） | 半成品（接完） | 未做（排期） |
|---|---|---|---|
| 对话 | 真流式、Router 规则、双闸门 | 浏览器工具闭环验证 | 云端路由（可关） |
| 语音 | STT、TTS Kokoro、RMS 端点 | Silero VAD 接线 | 唤醒词、barge-in、CosyVoice |
| 记忆 | hermes L0–L3 注入/沉淀 | 前端只读管理 | LLM 抽取、真向量 |
| 情绪 | PAD 注入 prompt | 接 TTS 语速、接 UI mood | — |
| 安全 | policy + 主进程终审 + 审计 | **信任等级设置 UI** | 通行证、审计查看器 |

**推荐总顺序**：安全可感知 → 情绪/形象闭环 → 记忆可见 → 语音增强 → 工具面收口。

## 1. 半成品清单与完善方案

### 1.1 信任等级 / 权限卡 UI（P0 · 安全）

| 项 | 内容 |
|---|---|
| 现状 | `src/renderer/utils/security/permissionCards.ts` 有 L0–L3 说明；**无设置入口**；只能手改 `agent/persona/xiyue.json` 的 `security.trust_level` |
| 目标 | 设置页可读写信任等级；展示「这个档位允许/需要确认什么」 |
| 方案 | ① 设置新增「AI · 信任与权限」卡：单选 L0–L3 + 卡片文案（复用 `TRUST_LEVEL_CARDS`）② 写回：IPC 或 store 文件 `xiyue.json`（或等价 store）③ 只读展示当前终审策略摘要 |
| 验收 | 改档位后对话工具高风险项行为变化；json 与 UI 一致 |
| 估工作量 | 中（1 个设置页 + 1 条 IPC） |

### 1.2 情绪 → TTS 语速（P1 · 体验）

| 项 | 内容 |
|---|---|
| 现状 | `_emotion_tts_speed()` 已定义**未调用** |
| 目标 | 情绪描述轻微影响语速（幅度小，避免怪异） |
| 方案 | final/TTS 前读当前 PAD → 映射 0.9–1.1 语速 → Kokoro/API 参数；日志可选 |
| 验收 | 高唤醒 vs 低唤醒语速有可感差异且不过分 |
| 估工作量 | 小 |

### 1.3 情绪 → 前端头像（P1 · 角色）

| 项 | 内容 |
|---|---|
| 现状 | 侧车 PAD 只进 prompt；UI `agentMood` 由 Agent phase 映射 |
| 目标 | 非任务期（idle 问候）可用情绪微调 happy/calm 等；任务期仍以 phase 优先 |
| 方案 | ① `GET /emotion` 或 SSE 附带 mood 字段 → store ② 优先级：agent phase > 情绪 > 默认 happy ③ 不与 `thinking/tool` 抢 |
| 验收 | 待机时表情随情绪有变化；工作中仍正确显示 tool/thinking |
| 估工作量 | 中 |

### 1.4 记忆管理（只读优先）（P1 · 可感知）

| 项 | 内容 |
|---|---|
| 现状 | hermes 已注入/沉淀；**无 UI** |
| 目标 | 用户能看见「汐月记住了什么」；先只读 |
| 方案 | ① 侧车 `GET /memory/list`（最近 N 条 L1/L0 摘要）② 设置或大面板「记忆」只读列表 ③ P2 再做删除/清空 |
| 验收 | 对话后列表出现新记忆；可一键「清空会话记忆」可选 |
| 估工作量 | 中 |

### 1.5 Silero VAD 接线（P1 · 语音）

| 项 | 内容 |
|---|---|
| 现状 | `voice/vad.py` 零调用；前端 RMS 已够用 |
| 目标 | 可选：更稳的端点；**不替换** RMS，作增强 |
| 方案 | 渲染层或侧车在录音尾段用 Silero 二次确认；配置开关「增强 VAD」默认关 |
| 验收 | 开关开/关均可完成一次语音→对话 |
| 估工作量 | 中（依赖模型与延迟调优） |

### 1.6 浏览器工具闭环（P1 · 工具）

| 项 | 内容 |
|---|---|
| 现状 | Playwright 客户端 + schema 6 工具；闭环未充分验证 |
| 目标 | 明确：要么产品可用，要么默认关闭并文档说明 |
| 方案 | ① 回归：打开页/点击/填表 ② 缺依赖则安装或设置「浏览器自动化」开关默认关 ③ 高风险一律 CONFIRM |
| 验收 | 开关关=不出现工具；开=安全操作可走授权卡 |
| 估工作量 | 中 |

## 3. 实施里程碑

### M-A1 · 安全可感知（优先）

1. 信任等级设置 UI（1.1）  
2. 工具审计只读列表（2.1 前半）  
3. 文案：设置内说明 L0–L3  

**验收**：用户不改 json 也能调安全档；看得到最近工具记录。

### M-A2 · 角色与情绪闭环

1. `_emotion_tts_speed` 接线（1.2）  
2. `/emotion` → store → 头像（1.3，phase 优先）  

**验收**：说话风格与表情对情绪有轻微、可控反馈。

### M-A3 · 记忆可见

1. `GET /memory/list`（只读）  
2. 设置或面板只读列表 + 可选清空会话记忆  

**验收**：聊完能在 UI 看到记忆条目。

### M-A4 · 语音增强（可选）

1. Silero VAD 开关（1.5）  
2. barge-in（2.3）  

### M-A5 · 工具面收口

1. 浏览器工具验证或默认关（1.6）  
2. 域白名单（2.7）  

### 明确后置

唤醒词、CosyVoice、云端路由、通行证完整版、记忆 LLM 抽取。
