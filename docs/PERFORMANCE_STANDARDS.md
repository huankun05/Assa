# 性能与资源工作规范

> 与根目录 [`AGENTS.md`](../AGENTS.md) §10 同步；细节与审查清单以 AGENTS 为准，本文补充汐月场景示例。

## 原则

**未使用的功能不启用；未选中的路径不请求；能销毁的隐藏窗不常驻。**

## 典型约束

### 1. 天气定位

| 用户选择 | 允许的定位来源 |
|----------|----------------|
| IP 定位优先 | IP → 自定义 → 缓存 |
| **自定义位置优先** | **仅自定义 → 缓存**（禁止 IP） |

- 实现参考：`src/renderer/store/slices/weatherSlice.ts`、`src/renderer/api/weather/weatherApi.ts`（`resolveWeatherAlertLocation`）
- VPN 场景：自定义位置不跟出口 IP 漂移

### 2. 后台服务与窗口

- 外部 Agent / Codex 等监视：默认关，设置打开才轮询
- 设置窗 / 独立窗：空闲预热 + 隐藏超时销毁；不在 `whenReady` 同步建全量重窗
- 预热路径避免「loading 页 → 再 load 应用」双重加载

### 3. 多数据源

- 主源成功即返回；备用源仅失败时调用
- 禁止「多打几家反正免费」作为默认行为

## 产品 IA：设置中心 vs 页面管理（2026-09-17）

| | **设置中心** | **页面管理** |
|--|-------------|-------------|
| 定义 | 真正的**行为/偏好/系统配置** | **显示什么**（可见性、顺序、内容清单） |
| 典型项 | 主题、动画、位置校准、交互行为、声音、通知、性能、网络、语言、快捷键、AI 隐私、天气源、音乐、账号更新 | 独立窗 Tab、**控制中心按钮**、展开/全展开导航布局、岛自定义页 |
| 不该放 | 哪些按钮/Tab 显示 | 主题色、音量、账号、安全等级 |

### 控制中心条

- 条上最多 **11** 个可见按钮  
- **设置**、**管理页面** 固定显示，不可隐藏  
- 编辑入口在 **页面管理 · 控制中心按钮**，不在设置一级导航

## 负一屏（Expanded 总览）接入说明（2026-09-16）

- **是什么**：Expanded 中间「大时钟 + 左右卡片」仪表盘（`OverviewTab`），产品向负一屏回归。
- **默认**：`expandTab` 默认 `overview`；导航配置 `EXPAND_CONFIGURABLE_TABS` 含 `overview`。
- **加载**：`ExpandedContent` 对 OverviewTab **lazy**；未切到总览不拉齐全部 widget。
- **相册**：负一屏不再提供「相册轮播」选项（本地相册下线）；音乐专辑字段不受影响。
- **性能**：未打开总览时不应加载 Overview 相关 chunk；打开总览再加载。
